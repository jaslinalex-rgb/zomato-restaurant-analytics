# Zomato Restaurant Analytics Dashboard

## Project Overview
Developed an interactive Power BI dashboard using a cleaned Zomato restaurant dataset. The dashboard provides insights into restaurant ratings, pricing, customer votes, online ordering trends, table booking availability, and location-wise restaurant distribution.

## Tools Used
- Python (Data Cleaning)
- Pandas
- Power BI
- GitHub

## Key Insights
- Top 10 restaurant locations
- Average restaurant ratings
- Cost for two analysis
- Online ordering trends
- Table booking availability
